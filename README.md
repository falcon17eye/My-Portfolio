# Mohammad Ibrahim — Game Designer Portfolio

> **Sharp Mind, Precise Eyes**

Personal portfolio website showcasing game design projects, GDDs, blog posts, and resume.

## 🛠 Tech Stack
- **HTML5** — Semantic markup
- **CSS3** — Custom properties, clip-path, CSS Grid, animations
- **JavaScript** — Vanilla JS, IntersectionObserver API
- **Design** — Persona 5-inspired UI with angular shapes and bold typography

## 📂 Structure
```
├── index.html              # Home page
├── resume.html             # Resume preview + download
├── projects/               # Individual project pages
│   ├── z-arena.html
│   ├── pong.html
│   ├── shine-oh-sun.html
│   └── dark-places.html
├── blog/                   # Blog system
│   ├── index.html
│   ├── my-game-design-process.html
│   └── what-makes-combat-feel-good.html
└── assets/
    ├── css/                # Modular stylesheets
    ├── js/                 # Navigation, animations, contact form
    ├── images/             # Project screenshots, blog images
    └── resume/             # Downloadable resume PDF
```

## 🚀 Deployment
Hosted on GitHub Pages. Push to `main` branch to deploy.

## 📝 To Customize
1. Replace placeholder project descriptions with your actual content
2. Add screenshots to `assets/images/projects/`
3. Place your resume PDF in `assets/resume/`
4. Create a [Formspree](https://formspree.io) account and update the form action in `index.html`
5. Update social links if needed
